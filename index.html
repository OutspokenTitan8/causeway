This device

Mark done is stored on this phone only. It does not update Causeway, and another phone will not see it.
iPhone: open this app on any working day. Safari can delete a site's saved data after seven days with no visit, which would clear your loaded jobs and every "done" mark. Daily use prevents that. Adding it to the Home Screen (Share → Add to Home Screen) also helps it qualify for protected storage.
Copy diagnostics puts a short summary on the clipboard - version, what is loaded and any errors - to paste into a message when something is wrong. Clear all data wipes this phone's copy of the export, the "done" marks and your settings. Neither one changes Causeway.
